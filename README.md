# 🧩 Peer Project Hub — Backend

This is the backend of **Peer Project Hub**, a MERN stack project enabling users to share and explore community projects with secure authentication and interactive features.

---

## 🚀 Live Backend API
Hosted on Vercel:  
👉 https://backend-final-project-gamma.vercel.app

Sample API endpoint:  
👉 https://backend-final-project-gamma.vercel.app/api/projects

---

## 🛠️ Tech Stack

| Area | Technology |
|------|------------|
| Backend Framework | Node.js + Express.js |
| Database | MongoDB (Mongoose) |
| Authentication | Firebase Auth (Token Validation) |
| Deployment | Vercel |

---

## 📌 API Features

✔️ CRUD operations for projects  
✔️ Comment system  
✔️ Favorites system  
✔️ Firebase middleware authentication  
✔️ Mongoose validation  
✔️ Secure REST API structure
